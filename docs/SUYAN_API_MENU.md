# 新素颜 API 群菜单

本文说明 QQ 官方机器人账号的 API 菜单配置与群内使用方式。菜单条目来自接口 catalog；第三方接口依赖外部服务，目录中存在某个条目不代表它当前可用。

## 配置账号

在「QQ 账号管理」添加或编辑官方机器人：

- **API菜单**：开启或关闭该账号的菜单，默认开启。管理员可关闭菜单。
- **菜单消息格式**：默认纯文本。管理员也可选择原生 Markdown 或模板 Markdown；这两种模式需要 QQ 开放平台授予相应权限。
- **菜单模板ID**：模板 Markdown 模式必填，填写 QQ 开放平台中对应的模板 ID，最多 128 个字符。
- **模板内容参数名**：仅模板 Markdown 模式显示；默认 `content`，首字符须为英文字母，其余字符须为英文字母、数字或下划线，最多 64 个字符。

模板内容只使用菜单正文的内容占位符，默认写 `{{.content}}`。如果将「模板内容参数名」改成其他值，应相应使用 `{{.<参数名>}}`；无需在模板里再添加其他菜单字段。

**菜单设置只保存本地账号配置，不会授予 QQ 开放平台权限。** Markdown 菜单按钮需要在开放平台为机器人开通 Markdown 和键盘权限。未获得所需权限时，菜单自动降级为文字页码指令。

## 在群里使用

群内请先 @ 机器人，再发送以下指令：

- **`菜单`**：打开第 1 页接口菜单。
- **`菜单 2`** 或 **`菜单2`**：打开第 2 页；菜单正文会给出上一页/下一页的完整指令。
- **`搜索接口 天气`**：按关键词搜索；搜索结果较多时，使用正文给出的带关键词页码指令继续翻页。

选择接口后，发送 `接口 编号或ID`，按提示逐项回复必填参数；也可一次发送 `接口 编号或ID 参数名=值`。填写过程中发送 `取消接口` 可取消。每页显示 8 项，数字编号为全目录编号；菜单标记为“仅文档”的接口不会执行调用。

## 接口目录和可用性

菜单目录由实际 catalog 提供，而不是对每个部署、每个时刻都固定的静态清单。catalog 数量与接口内容可能变化；显示在目录中的接口不代表第三方服务当时可用，也不承诺接口实时可调用。第三方服务的可用性、网络和接口参数约束均可能影响调用结果；本说明不表示所有第三方接口均已实测。

无法解析的 catalog 条目仍保留在目录中，并显示未解析原因，方便管理员了解该条目为何不能按常规方式调用。接口响应可能包含图片或视频链接；资源能否加载仍取决于对应外部服务和链接的可用性。
