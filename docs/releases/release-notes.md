# 更新历史

## v1.3.1（2026-11-14）

- 修复仪表盘图表 X 轴日期标签被下方面板遮挡的问题（桌面与移动端均已验证）。
- 修复群聊管理、系统日志、申请审核等页面点击「刷新」后弹出无文字错误提示的问题；错误提示现在始终带具体原因。
- GitHub 项目更新通知排版优化：Release 正文里的资产表格转为纯文本单行，去掉重复的下载地址段落，过滤 blockmap / latest.yml / 校验清单等更新器元数据行。
- 通知里同一批下载链接只出现一次；正文没有列资产时仍会自动附上「下载与发布资产」。

### 升级说明

- 通过后台「系统设置 → 在线更新 → 立即升级」完成升级；升级期间机器人短暂中断约几秒，完成后页面自动刷新。
- 若系统设置里保存过自定义「推送默认模板」，升级后仍以自定义模板为准；删除该设置即可使用新版内置格式。

## v1.3.0（2026-11-14）

- 在线更新新增「立即升级」：点击后由服务器自动下载正式版、校验文件、备份数据、安装并重启机器人服务。
- 后台显示升级进度；服务重启时自动等待恢复，完成后刷新到新版本。重复点击不会创建多份安装任务。
- 新版本在独立目录准备，启动检查期间暂停对外写入及推送任务；检查失败时恢复旧版本和升级前的数据，保留失败记录供排查。
- 账号、群绑定、密钥、推送历史和邮件授权保存在原数据目录，升级后继续使用。
- 发布附件增加包含完整前端的 `native.tar.gz` 升级包；支持已安装独立升级服务的原生 Linux / systemd / SQLite 部署。

### 升级说明

- 旧版本第一次需要安装升级入口，按 `docs/NATIVE_SERVER.md` 配置一次宿主机升级服务；后续版本可直接点击后台「立即升级」。
- Docker 或自定义部署未接入升级服务时，后台会显示实际不可用原因；保留原部署升级方式，不会将下载成功显示成安装完成。
- 升级会短暂中断访问，页面会自动等待服务恢复。保留原 `SECRET_KEY`、数据目录和服务器环境配置。

## v1.2.0（2026-11-14）

- QQ 接入仅保留官方机器人，通过 AppID / AppSecret 连接，支持 WebSocket 或 Webhook；升级保留现有官方群绑定和通知历史。
- GitHub Token 一次接入全部仓库，自动发现新项目，支持提交、PR、Issue、评论和新版本通知；多个通知群可独立绑定、启停和检查主动消息权限。
- GitHub 仓库删除或不可访问时，自动从当前监控清单和数量统计中移除，并保留历史记录。
- 新用户可按步骤设置机器人、仓库、群授权与通知；帮助文档支持搜索，并展示 QQ 设置截图及放大预览。
- 失败邮件可在后台配置 Agent Mail / SMTP 发信账号、收件邮箱和提醒类型，并查看发信与重试记录。
- 支持后台查看新版本信息，提供源码上传包、容器部署和原生 Linux 常驻服务配置。

### 升级说明

- 升级前备份数据库，并保留原 `SECRET_KEY`，以继续使用已经加密保存的 QQ / GitHub 凭据。
- 升级会自动停用旧的非官方接入与相关任务、规则，保留历史数据；现有官方群绑定继续使用。
- Agent Mail 从 Windows 迁移到 Linux 后需要在新服务器上重新授权发信账号。
- 下载 ZIP 上传包或源码归档后按 `DEPLOYMENT.md` 操作；单机原生部署可参考 `docs/NATIVE_SERVER.md`。
