# 更新历史

## v1.2.0（2026-11-14）

- QQ 接入仅保留官方机器人，通过 AppID / AppSecret 连接，支持 WebSocket 或 Webhook；升级保留现有官方群绑定和通知历史。
- GitHub Token 一次接入全部仓库，自动发现新项目，支持提交、PR、Issue、评论和新版本通知；多个通知群可独立绑定、启停和检查主动消息权限。
- GitHub 仓库删除或不可访问时，自动从当前监控清单和数量统计中移除，并保留历史记录。
- 新用户可按步骤设置机器人、仓库、群授权与通知；帮助文档支持搜索，并展示 QQ 设置截图及放大预览。
- 失败邮件可在后台配置 Agent Mail / SMTP 发信账号、收件邮箱和提醒类型，并查看发信与重试记录。
- 支持后台查看新版本信息，提供源码上传包、容器部署和原生 Linux 常驻服务配置。

### 升级说明

- 升级前备份数据库，并保留原 `SECRET_KEY`，以继续使用已经加密保存的 QQ / GitHub 凭据。
- 升级会自动停用旧的非官方接入与相关任务、规则，保留历史数据；现有官方群绑定继续使用。
- Agent Mail 从 Windows 迁移到 Linux 后需要在新服务器上重新授权发信账号。
- 下载 ZIP 上传包或源码归档后按 `DEPLOYMENT.md` 操作；单机原生部署可参考 `docs/NATIVE_SERVER.md`。
