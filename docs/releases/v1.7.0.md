## 📢 版本概述

本次更新为 QQ 官方机器人新增群内 API 菜单：在群里 @ 机器人即可浏览分页接口目录、搜索接口并逐项调用，管理员可为每个账号开关菜单并选择消息格式。菜单目录来自经过安全审核的静态 catalog，只保留目录中已明确审核的只读接口可执行；不涉及数据库迁移，旧版本升级后配置与数据保留不变。

## ✨ 新增功能

- **群内 API 菜单**：@ 机器人发送「菜单」查看第 1 页，「菜单 2」或「菜单2」翻页，「搜索接口 天气」按关键词查找；发送「接口 编号或ID 参数名=值」直接调用，或按提示逐项回复参数，填写过程中可随时「取消接口」。
- **菜单消息格式**：账号设置可选纯文本（默认）、原生 Markdown 或模板 Markdown；模板模式填写 QQ 开放平台的模板 ID 与内容参数名（默认 `content`，模板写 `{{.content}}`）。未获平台权限或卡片被拒时自动降级为文字页码指令，每次回复只落库一条消息。
- **接口目录与搜索**：菜单每页 8 项，数字编号为全目录编号；catalog 中未解析的条目保留在目录并显示不可执行原因，「仅文档」标记的接口不会发起调用。
- **目录同步脚本**：`scripts/sync_suyan_catalog.py` 从素颜公开文档抓取并生成带解析状态、安全审核结论的静态 catalog（`backend/app/data/suyan_apis.json`，当前 299 项），配套离线缓存与重试测试。

## 🔧 改进与优化

- **后台执行通道**：接口调用走独立后台队列（单账号 4、全局 16），慢请求不再阻塞菜单翻页和同账号其他群消息；重复请求被拒收并提示稍后再试。
- **会话衔接**：参数填写中无需前缀可直接回复内容；账号关闭 API 菜单、接口命令被禁用或权限变化时，进行中的填写会话会被取消并说明原因。
- **帮助与文档**：帮助中心新增《官方 API 菜单：设置与使用》；账号页官方机器人说明补充菜单用法；新增 `docs/SUYAN_API_MENU.md` 说明配置、目录来源与可用性边界。

## 🐛 问题修复

- 修复带 Markdown 卡片的回复在降级重发时把卡片和纯文本各落库一次的问题；现在每次投递最终只保存一条 out 消息。
- 修复菜单与帮助命令别名冲突：「菜单」固定指向 API 功能菜单，「帮助」继续列出可用命令，二者互不影响。

## 🔒 安全与兼容性

- **目录即白名单**：运行时只执行 catalog 中已明确审核、文档完整的 HTTPS 只读接口，且目标固定为 `api.suyanw.cn`；请求经 SSRF 目标校验，禁止重定向，带外超时。catalog 中其余条目仅作展示，不会被调用。
- **权限沿用**：菜单与接口命令遵守现有命令权限与群命令开关；管理员可按账号整体关闭 API 菜单。
- **升级兼容**：无数据库迁移、无配置变更；v1.6.0 及更早版本可直接升级，账号、密钥、推送规则与会话数据不受影响。旧版本更新检查器对比 GitHub 最新稳定 tag，发布后可在管理台正常收到 v1.7.0 提醒。

## 🔄 升级与数据迁移

- **兼容性**：无数据库迁移，schema 保持 `0018_runtime_recovery` 不变；新旧版本不会因数据结构冲突混写。
- **配置和数据**：账号菜单设置默认开启、消息格式默认纯文本，无需手动迁移；已有命令开关与权限继续生效。
- **回退方式**：可按常规流程切回 v1.6.0 代码与快照；旧版本不识别新增账号菜单配置字段，回退后这些字段被忽略但不会损坏数据。

## ⚠️ 已知问题

- 第三方接口可用性取决于素颜服务与上游接口当时的状况，本项目不承诺任何未实测接口可实时调用；「仅文档」条目始终不会执行。
- Markdown 菜单按钮需要 QQ 开放平台为机器人开通 Markdown 与键盘权限；后台的菜单设置不会授予平台权限，缺权限时自动退回文字菜单。
- 群内使用菜单需先 @ 机器人；QQ 客户端不支持自动发送 `type=2` 指令按钮时，点击按钮后确认发送即可。
