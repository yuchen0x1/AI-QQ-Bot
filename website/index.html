为什么选择 QBot AI

从机器人接入到运维安全，一个平台覆盖 QQ 机器人运营的全部环节。

官方机器人接入

基于 QQ 开放平台官方机器人：AppID + AppSecret 凭据接入，Gateway WebSocket 长连接或 Ed25519 验签 Webhook，自动重连与 Resume 会话恢复。

多账号隔离

多个官方机器人账号同时在线、互不干扰；插件、群聊、任务与推送按账号独立绑定，OpenID 自动映射为稳定内部 ID。

AI 多供应商

OpenAI 兼容 Provider、多模型管理、会话上下文与失败自动降级；API Key 加密存储、界面脱敏，群聊 @ 机器人即可触发 AI 回复与总结。

GitHub 仓库群通知

Token 一次连接、自动发现新仓库；提交、PR、Issue、Release 等事件实时推送到多个群，支持 AI 更新摘要、事件去重与失败重试。

失败邮件提醒

Agent Mail / SMTP 发信账号可视化配置，推送失败、任务异常自动邮件告警；发信队列持久化、自动重试，附带发信测试。

定时任务与插件

APScheduler 持久化定时群消息与执行记录；插件目录自动扫描，按账号 / 群灵活绑定，定时推送与群聊总结开箱即用。

一体化控制台

Vue 3 + Element Plus 管理后台：仪表盘、账号、群聊、审核、AI、仓库、推送规则、任务、插件、日志、监控、系统设置一应俱全。

在线一键升级

后台「立即升级」：服务器自动下载、SHA-256 校验、备份、安装并重启，网页实时显示进度；失败自动回滚到原版本。

安全内建

JWT 登录、RBAC 权限、TOTP 两步验证、登录失败锁定、会话设备管理、敏感配置加密、操作审计与请求限流，默认只监听回环地址。

两种官方接入方式，按需选择

均基于 QQ 开放平台官方机器人凭据，无需扫码登录、无需逆向协议。

推荐 · 无需公网回调

WebSocket 长连接

平台主动连接 QQ 官方 Gateway，服务器无需暴露公网回调地址。

  • Identify / Heartbeat / Resume 全流程实现
  • 断线自动退避重连、会话恢复
  • 本地调试无需公网 IP 与域名
  • 适合家宽 / 内网环境部署
无需出站长连接

Webhook 验签回调

平台把事件推送到你的 HTTPS 回调地址，本地自动应答 op=13 验证并验签每一笔推送。

  • AppSecret 派生 Ed25519 密钥，与官方 DEMO 逐字节对齐
  • 回调地址形如 https://your-domain.example/api/qqbot/webhook/{AppID}
  • 时间窗验签防重放，多实例部署天然亲和
  • 签名失败原因记录到账号日志，方便排障

三步部署到你的服务器

需要一台 Linux 服务器与 Docker Compose v2；后续升级可直接在后台一键完成。

1

克隆仓库并配置

复制 .env.example 为 .env，填入随机生成的 SECRET_KEY 与数据库、Redis 强密码。

2

启动整套服务

docker compose up -d --build 一键拉起 frontend、backend、postgres、redis、nginx 五个容器。

3

接入官方机器人

QQ 开放平台创建机器人，取得 AppID / AppSecret 填入后台「账号管理」，测试连接后启动即可。

$ cp .env.example .env $ python3 -c 'import secrets; print(secrets.token_urlsafe(48))' # 用生成的值填写 SECRET_KEY，并替换 POSTGRES_PASSWORD、REDIS_PASSWORD、ADMIN_PASSWORD $ docker compose up -d --build $ docker compose logs -f backend ✔ 页面默认 http://127.0.0.1:8080，建议由 HTTPS 反向代理接入
